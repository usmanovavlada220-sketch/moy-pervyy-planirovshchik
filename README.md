# Мой первый планировщик - Planning

Локальный планировщик задач и встреч для Mac. Данные хранятся в браузере, сервер и интернет не нужны.

## Первый запуск

1. Распакуйте комплект в постоянную папку.
2. Оставьте рядом три файла: `index.html`, `style.css`, `script.js`.
3. Откройте `index.html` в Chrome или Safari двойным щелчком или через «открыть с помощью».
4. Выберите оформление в «фон доски»: мягкое с розовыми акцентами или графит. Общие настройки находятся в верхней панели.

Не открывайте приложение прямо из ZIP. Не перемещайте его папку и не меняйте браузер без резервной копии: доступ к сохранению локальной страницы зависит от браузера и пути файла.

## Повседневная работа

- Добавляйте задачи кнопкой «+». В карточке доступны описание, рабочая/личная метка, срочность, срок и чек-лист.
- Перетаскивайте карточки за ручку или используйте меню «•••». При активных фильтрах перестановка отключена, но изменение статуса через меню доступно.
- Планируйте неделю по статусам. «Позже» - общий список, не привязанный к неделе.
- Нажмите «выполнить», чтобы отправить задачу в архив. Восстановление доступно из архива. Корзина предназначена для удалённых задач.
- При открытии после смены недели незавершённые задачи автоматически переносятся в текущую неделю. Прошлая сводка сохраняется.
- В месяце и квартале доступны результаты и диаграммы. Отмечайте значимые задачи «важное для отчёта», сохраняйте заметки по итогам месяца отдельной кнопкой.
- Для встречи выберите день в календаре, нажмите «+» рядом с заголовком «встречи» и укажите название и время. Совпадения требуют подтверждения.
- Напоминания работают только в открытой странице. Для сигнала раскройте «напоминания и звук», нажмите «включить звук», затем «проверить звук». После нового запуска браузера может понадобиться повторное включение.
- Компактный режим показывает ближайшие встречи в той же вкладке, без системного виджета.

## Оформление и клавиши

Темы: светлая, тёмная, как в системе и по времени суток (светлая с 07:00 до 20:00 по времени компьютера). Для светлого и тёмного режима можно отдельно задать цвета через палитру или HEX. Контрастный чёрный/белый текст меток и акцентных кнопок подбирается автоматически. Изменения настроек сохраняются сразу; неверное значение не применяется.

Названия четырёх колонок можно изменить, их смысл и количество сохраняются. Личный фон и вариант «графит» выбираются отдельно для досок. Общая настроенная палитра имеет приоритет над готовыми акцентами. Выбор фона в окне «фон доски» отключает общий фон текущей темы. Сброс оформления требует подтверждения и не удаляет задачи, встречи и историю.

Вне полей ввода, кнопок и диалогов работают физические клавиши:

- `N / Т` - новая задача на доске.
- `T / Е` - текущая неделя.
- `/` - поиск.
- `← / →` - предыдущий или следующий период.
- `Escape` - закрытие меню/диалога, отмена переноса. При несохранённых данных появляется подтверждение.

Команды приложения отключаются в настройках. Обычные команды браузера, включая ⌘N, ⌘F и ⌘R, не заменяются.

## Резервные копии

Регулярно открывайте «резервная копия» и скачивайте JSON. Он содержит все доски, задачи, встречи, историю, заметки и настройки.

Восстановление из файла **полностью заменяет** текущее сохранение. Перед импортом сохраните прежнюю копию. Не редактируйте одну и ту же локальную копию одновременно в разных вкладках: при обнаружении конфликта запись останавливается и предлагается перечитать сохранение.

Не используйте приватный режим для постоянной работы. Очистка данных браузера может удалить планировщик из его хранилища. Файлы приложения сами по себе не являются резервной копией ваших задач.

## Для второго пользователя

Передайте ZIP с приложением и этой инструкцией. Не добавляйте вашу JSON-копию. На другом компьютере пользователь начинает с пустого планировщика и ведёт независимые данные. Совместная синхронизация и аккаунты не предусмотрены. Обычные доски внутри одного браузерного сохранения не являются защищёнными отдельными аккаунтами.

## Проверка версии от 24 октября 2026 года

Проверено в Chrome на изолированных данных: основные действия, сохранение, переносы, отчёты, встречи, резервные копии, настройки, клавиши и адаптация окна. Для напоминаний проверены условия показа и звуковые вызовы, а не фактическая слышимость через динамики пользователя.

Автоматическая проверка Safari недоступна: SafariDriver сообщил, что выключено разрешение удалённой автоматизации. Настройки Safari не менялись. Работа этой версии в Safari не считается подтверждённой. Основной проверенный браузер - Chrome.

## Статистика и дедлайны

Недельная статистика скрыта по умолчанию. Кнопка «статистика недели» раскрывает её и запоминает выбор. «Всего за неделю» включает выполненные задачи; «открытые задачи» показывает оставшиеся.

Поле «дедлайн» выделяет активную карточку: серо-синий - будущий срок, янтарный - сегодня, красный - просрочено. Рядом указаны текст и дата. Завершённая карточка не подсвечивается как просроченная.

## Главное на неделю

Введите главный пункт и нажмите Enter или «добавить». Можно добавить несколько пунктов, затем изменить или удалить каждый. Они показываются над колонками, сохраняются отдельно для каждой недели и доски и не влияют на статистику задач.

Круг выполнения недели виден постоянно; кнопка «статистика недели» раскрывает только подробные цифры. Это уточнение заменяет описание скрытия всей статистики выше.


## Обновление после итоговой сверки

Новая задача учитывает фильтр «рабочие/личные». В открытой задаче доступно «выполнить». На узком экране используйте переключатель статусов и кнопку «встречи»; поиск раскрывается своей кнопкой. Месяц показывает недели сверху вниз.

Проверено в Chrome 156.0.8078.47 на macOS 26.6.2. Итоговая проверка Safari пока не завершена из-за недоступной автоматизации. Резервные копии храните отдельно от комплекта приложения.


Календарь можно убрать кнопкой «скрыть встречи» и вернуть кнопкой «показать встречи».
На компьютере выбор сохраняется после обновления страницы, доска расширяется.
Напоминания продолжают работать.
